02 · Course Modules

课程模块

Course Modules
MODULE 01

AI 短剧全流程搭建

从剧本到成片的完整制作流程——从剧本处理、人物资产规划到运镜执行，搭建可落地的完整 AI 制作剧流程与人员排期方案。

MODULE 02

提示词工程与人机沟通

让 AI 精准理解创作意图——提示词拆解与编写方法论，规避过审风险，提升生成正确率，让 AI 精准理解创作意图。

MODULE 03

让画面具备专业叙事感——剧本的影视化拆解思维，动态分镜生成与运镜语言设计，让画面具备专业叙事感。

MODULE 04

人物资产与审美评估

建立统一的视觉风格——人物形象资产规划、生成质量评估与审美把控，建立统一、贴近大众审美的视觉风格。

MODULE 05

AI 商业视觉与 IP 设计

好看之外，更要真实转化——AI 商业海报、宣传片与企业 IP 形象设计，让内容既好看、又能带来真实商业转化。

MODULE 06

短剧市场与商业变现

讲清楚 AIGC 影视的变现路径——解读短剧市场受众与内容逻辑，结合作品定位讲清楚 AIGC 影视的变现路径。
